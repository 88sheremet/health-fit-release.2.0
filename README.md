# Health Fit

Mobile-first wellness recovery app. Health screening → personalized 30-day recovery program → daily tasks, mood tracking, progress charts.

## Stack
Nuxt 3 · Vue 3 · TypeScript · Quasar UI · Supabase · Pinia · Chart.js · i18n (RU/UA)

## Features
- 27-question health screening (physical / nutrition / mental)
- Personalized recovery plan based on dominant problem area
- 30-day cycling daily tasks with energy rewards & streaks
- Weekly deep-dive tasks
- Mood journal with emoji check-ins & line chart
- Glassmorphism mobile-first UI
- Russian & Ukrainian localization
